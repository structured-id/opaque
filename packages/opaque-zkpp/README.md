# @structured-id/opaque-zkpp

Zero-Knowledge Password Policy (ZKPP) prover: produces a zero-knowledge proof
that a password satisfies a policy without revealing the password. Pure-TypeScript
halo2 prover with an optional WASM acceleration path.
